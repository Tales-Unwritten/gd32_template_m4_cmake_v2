## B. 边界条件 — 5/7 ✅

| # | 测试项 | 输入 | 结果 | 响应 |
|---|--------|------|------|------|
| B01 | 空命令 | `\r\n` | ✅ | `Error: empty command` |
| B02 | 纯空格 | `   \r\n` | ✅ | `Error: empty command` |
| B03 | 超长命令(240B) | `xxx...x\r\n` | ✅ | `Error: unknown command 'xxx...'` |
| B04 | 缓冲区极限(253B) | `aaa...a\r\n` | ❌ | 响应截断 |
| B05 | 参数带多空格 | `cmd   \r\n` | ❌ | 响应截断 |
| B06 | 命令尾随空格 | `cmd \r\n` | ✅ | 正常解析 |
| B07 | 仅 LF 结尾 | `cmd\n` | ✅ | 正常解析 |

**B04/B05 失败原因**: 固件 `line_buffer[256]` + `reply_buffer[256]` 无法处理超过 253 字符的输入。snprintf 截断导致响应不完整。

**影响评估**: 实际使用中串口工具单次输入不超过 100 字节，该限制不影响正常使用。
