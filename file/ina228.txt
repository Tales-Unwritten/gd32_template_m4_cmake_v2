3 说明
INA228-Q1 是一款超精密数字功率监控器,配备专为电流检测应用而设计的 20 位 Δ-Σ ADC。该器件可跨共模电压支持范围为 -0.3V 至 +85V 的电阻式分流器感测元件测量 ±163.84mV 或 ±40.96mV 的满量程差分输入。

INA228-Q1 报告电流、总线电压、温度功率、能量和电荷累积,并采用精度为 ±0.5% 的集成振荡器,同时在后台执行所需的计算。集成的温度传感器用于裸片温度测量的精度为 ±1°C,并可用于监测系统环境温度。

INA228-Q1 采用低温漂和增益漂移设计,以使此器件可用于在制造过程中不进行多温度校准的精密系统。此外,非常低的失调电压和噪声允许在 mA 至 kA 感测应用中使用,并在感应分流器元件上提供宽的动态范围而不会产生显著的功率损耗。该器件的低输入偏置电流允许使用较大的电流检测电阻器,从而能够提供微安级的精确电流测量。

该器件允许选择从 50µs 到 4.12ms 的 ADC 转换时间以及从 1x 到 1024x 的采样平均值,这有助于进一步降低测量数据的噪声。

7 详细说明
7.1 概述
INA228-Q1 是一款带I2C数字接口的数字电流检测放大器。可测量分流电压、总线电压、裸片温度，同时计算电流、功率、能量、电荷，适用于高精度控制系统。可编程寄存器可灵活配置测量精度、连续/触发工作模式。寄存器详细定义见7.6章节。

7.2 功能框图
VS、Reference、Power、IN+、IN-、MUX、20Bit ADC、Oscillator、Voltage/Current/Energy/Charge/Temp运算模块、I2C接口(SCL/SDA)、地址引脚A0/A1、告警ALERT、地GND、阈值比较模块。

7.3 功能特性说明
7.3.1 宽高压测量能力
器件工作电源2.7~5.5V，可测量最高85V母线电压电流。通过IN+/IN-外接采样电阻检测电流，输入共模电压可高于器件供电电压，范围-0.3V~85V，支持高端/低端电流检测。
共模输入与器件供电相互独立，无需上电时序匹配，母线可先于器件上电，不会损坏芯片。
VBUS引脚测量对地母线电压，温度传感器测量范围-40℃~+125℃。分流电压、母线电压、温度通过多路复用器接入单颗ADC。

7.3.2 内部测量与计算引擎
分流电压测量后计算电流、电荷；母线电压测量后计算功率、能量。功率/能量基于前一次电流和最新母线电压计算。若SHUNT_CAL寄存器置0，功率、能量、电荷读数均为0。
平均值模式下，多次采样累加后输出平均电流电压，再计算功率；能量和电荷按每个转换周期持续累加，不受平均采样影响。
功率、能量、电荷后台运算，不占用ADC转换时间。

7.3.3 低输入偏置电流
极低偏置电流可降低器件静态功耗、支持输入滤波抑制高频噪声、允许使用大阻值采样电阻实现微安级小电流精确检测。
偏置电流在检测电流为0时最小，随采样电阻压差增大略有上升。

7.3.4 高精度Δ-Σ ADC
内置低失调、低温漂ADC，支持双向电流检测。适配宽温度、共模电压、电源波动下的稳定测量，低失调最大化系统动态范围。
分流/母线/温度转换时间可独立配置50µs~4.12ms，平均采样1~1024倍，降低测量噪声。
支持连续转换、触发转换两种模式；可单独或组合测量分流/母线/温度。转换完成后数据自动刷新寄存器，读取不打断转换进程。
触发模式下能量/电荷累加无效，需连续模式才能精准统计能耗与电量。
可配置0~510ms转换延迟，步长2ms，用于多器件测量同步。

7.3.4.1 低延迟数字滤波器
内置低通数字滤波，兼具抽取与降噪功能，自适应输出速率，单个转换周期内完成稳定。滤波陷波频率fNOTCH=1/(2×TCT)，截止频率随输出速率线性缩放。

7.3.4.2 灵活转换时间与平均采样
三路测量转换时间独立配置，平均采样全局生效。增大转换时间和平均次数可提升有效分辨率ENOB。

7.3.5 采样电阻温漂补偿
内置温度传感器测量裸片温度-40℃~+125℃，全温区精度±2℃。可开启采样电阻温度补偿功能，配置SHUNT_TEMPCO寄存器写入电阻温漂系数（最大16384ppm/℃），以25℃为基准自动修正电流读数。
补偿公式：
RADJ = RNOM + [RNOM×(DIETEMP-25)×SHUNT_TEMPCO]/10^6
注意：高分流电压、高阻温漂、高温工况下，补偿后电流读数可能偏低。

7.3.6 精密内部振荡器
室温精度<0.5%，全温区<1%，为ADC转换、能量电荷计时提供基准。上电300µs内时钟误差收敛至1%以内，保证滤波和时序精度。

7.3.7 多告警与故障检测
ALERT为开漏多功能输出，可上报各类故障、转换完成标记。支持故障阈值上下限配置，包含：分流过压/欠压、母线过压/欠压、过温、功率超限。
支持告警锁存、转换完成告警、平均数据告警比较、告警极性配置；可检测数学溢出、存储器异常、能量/电荷溢出等状态。

7.4 器件工作模式
7.4.1 关断模式
通过ADC_CONFIG寄存器配置进入关断模式，静态电流降至5µA以下，关闭输入电流损耗。关断模式下可正常读写寄存器，触发单次转换后自动返回关断。
总线通信频繁会增加关断功耗。

7.4.2 上电复位POR
电源电压低于典型1.26V触发复位，所有寄存器恢复默认值；可通过CONFIG寄存器RST位软件复位。

7.5 编程配置
7.5.1 I2C 串行接口
器件仅作为I2C/SMBus从设备，SDA/SCL开漏结构，集成尖峰抑制和施密特触发器。支持标准100kHz、快速400kHz、高速2.94MHz模式，数据高位先行，兼容SMBus3.0协议。
A0/A1地址引脚可配置16种不同从机地址，可接GND/VS/SDA/SCL。

7.5.1.1 I2C 读写时序
写操作：从机地址(写)→寄存器地址→高字节→低字节
读操作：先写寄存器指针→重复起始→从机地址(读)→读取高/低字节
支持重复读同一寄存器无需重设指针，不支持PEC校验和时钟拉伸。

7.5.1.2 高速I2C模式
空闲时总线上拉至高电平，主机先发高速码切换至2.94MHz，重复起始维持高速模式，停止位退出高速模式。

7.5.1.3 SMBus告警响应
支持SMBus告警地址响应，多从机告警时总线仲裁识别故障器件。

8 应用与设计实现
8.1 应用基础信息
8.1.1 测量范围与分辨率
分流量程：±163.84mV / ±40.96mV
母线量程：0~85V
温度量程：-40℃~+125℃

| 参数 | 满量程 | 分辨率LSB |
| --- | --- | --- |
| 分流电压 ADCRANGE=0 | ±163.84mV | 312.5nV/LSB |
| 分流电压 ADCRANGE=1 | ±40.96mV | 78.125nV/LSB |
| 母线电压 | 0~85V | 195.3125µV/LSB |
| 温度 | -40~+125℃ | 7.8125m℃/LSB |

8.1.2 电流/功率/能量/电荷计算公式
1. 电流LSB：CURRENT_LSB = 最大预期电流 / 2^19
2. 校准寄存器：SHUNT_CAL = 13107.2×10^6 × CURRENT_LSB × RSHUNT
   ADCRANGE=1时，SHUNT_CAL需×4
3. 实际电流(A) = CURRENT_LSB × 寄存器读数
4. 功率(W) = 3.2 × CURRENT_LSB × 功率寄存器读数
5. 能量(J) = 16 × 3.2 × CURRENT_LSB × 能量寄存器读数
6. 电荷(C) = CURRENT_LSB × 电荷寄存器读数

能量/电荷溢出后自动归零，可通过RSTACC位手动清零累加值。

8.1.3 ADC速率与噪声性能
转换时间、平均采样次数直接影响无噪声有效位数ENOB。

8.1.4 输入滤波设计建议
输入串阻建议≤100Ω，搭配0.1~1µF陶瓷电容做RC滤波；差分输入耐压±40V，感性负载需增加稳压管抑制感应尖峰；串10Ω电阻可抑制dV/dt冲击损坏。

8.2 典型应用电路
8.2.1 设计参数示例
| 参数 | 示例值 |
| --- | --- |
| 供电电压 VS | 5V |
| 母线共模电压 | 48V |
| 母线过压阈值 | 52V |
| 平均工作电流 | 6A |
| 过流阈值 IMAX | 10A |
| ADC量程 | ±163.84mV |
| 工作温度 | 25℃ |
| 电荷累积周期 | 1小时 |

8.2.2 详细设计步骤
1. 采样电阻选型：RSHUNT < VSENSE_MAX / IMAX，计算得16.38mΩ，选用标准16.2mΩ；需校验电阻功耗。
2. 器件配置：上电初始化CONFIG、ADC_CONFIG寄存器。
3. 校准寄存器计算：配置SHUNT_CAL数值。
4. 故障阈值配置：配置过流、过压、欠压、过温、功率超限寄存器阈值。
5. 读数换算：按LSB系数将寄存器原始值转为实际电压/电流/功率/能量/温度。

8.2.3 应用时序曲线
告警响应时间：阈值超限严重时最小12.4µs、最大37.9µs；阈值临界超限24µs~73.2µs；工程设计按1.5倍转换时间预留告警延迟。

9 电源设计建议
器件可测量高于自身供电的共模电压，输入引脚无供电时也可承受0~85V电压；禁止器件上电时断开GND引脚。
电源就近放置0.1µF旁路电容，高噪声电源可增加多级去耦。

10 PCB布局指南
10.1 布局规则
1. 采样电阻必须开尔文四线接法接入IN+/IN-，避免走线附加电阻带来测量误差；
2. 电源旁路电容紧靠VS和GND引脚；
3. I2C走线短且平行，用地平面隔离降低串扰；
4. ALERT、地址引脚走线远离功率走线。
